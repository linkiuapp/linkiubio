# Dashboard - Documentación para KiuBot Assistant

## Cómo usar el Dashboard

El Dashboard es tu panel principal donde puedes ver un resumen completo de tu tienda:

1. En el menú lateral, ve a la sección "Favoritos"
2. Haz clic en "Dashboard" (o simplemente inicia sesión, ya que es la página principal)
3. Verás las siguientes secciones:

## Estadísticas de Pedidos

El dashboard muestra tarjetas con estadísticas de tus pedidos:
- Total de pedidos: Cantidad total de pedidos recibidos
- Pendientes: Pedidos que aún no han sido confirmados
- Confirmados: Pedidos confirmados y listos para prepararse
- Preparando: Pedidos que están siendo preparados
- Enviados: Pedidos que han sido enviados
- Entregados: Pedidos completados exitosamente

## Pedidos Recientes

En la parte inferior del dashboard verás una lista de tus pedidos más recientes con:
- Número de pedido
- Cliente
- Fecha
- Estado
- Total

Puedes hacer clic en cualquier pedido para ver sus detalles completos.

## KiuBot Assistant

En el dashboard encontrarás el asistente virtual KiuBot que te ayuda a:
- Aprender a usar todas las funcionalidades de Linkiu
- Entender cómo funciona cada sección del menú lateral
- Resolver dudas sobre la plataforma
- Obtener sugerencias y recomendaciones

## Información adicional

- El dashboard se actualiza en tiempo real con la información más reciente
- Puedes acceder rápidamente a cualquier sección desde el menú lateral
- Los anuncios importantes de Linkiu aparecen en la parte superior del dashboard
- Usa las estadísticas para monitorear el rendimiento de tu tienda
