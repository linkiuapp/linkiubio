# Variables - Documentación para KiuBot Assistant

## Cómo crear una variable

Para crear una variable (como tallas, colores, sabores, etc.) en Linkiu, sigue estos pasos:

1. En el menú lateral, ve a la sección "Tienda y productos"
2. Haz clic en "Variables"
3. En la parte superior derecha, haz clic en el botón "Nueva Variable"
4. En el formulario, completa estos campos:
   - Nombre (requerido): Ingresa el nombre de la variable, por ejemplo "Talla", "Color", "Sabor"
   - Tipo (requerido): Selecciona el tipo de variable:
     - Radio: El cliente solo puede seleccionar una opción
     - Checkbox: El cliente puede seleccionar múltiples opciones
     - Texto: El cliente ingresa texto libre
     - Numérico: El cliente ingresa un número
   - Ícono (opcional): Selecciona un ícono para identificar la variable visualmente
5. Agrega los valores posibles (opciones):
   - Haz clic en "Agregar Opción"
   - Ingresa el nombre de la opción, por ejemplo "S", "M", "L", "XL" para Talla
   - Si es un color, puedes seleccionar un color hexadecimal
   - Puedes agregar múltiples opciones
6. Activa o desactiva la variable según quieras usarla
7. Haz clic en el botón "Guardar"

## Cómo editar una variable

1. Ve a "Variables" en el menú lateral
2. Haz clic en la variable que quieres editar
3. Modifica los campos que desees
4. Puedes agregar, editar o eliminar opciones
5. Haz clic en "Guardar"

## Cómo usar variables en productos

1. Al crear o editar un producto, selecciona el tipo "Variable"
2. En la sección "Variables", selecciona las variables que aplican a ese producto
3. Si es necesario, crea las variaciones del producto con sus precios y stock específicos
4. Guarda el producto

## Información adicional

- Las variables permiten que tus productos tengan opciones como tallas, colores, sabores, etc.
- Los clientes podrán seleccionar las variantes al agregar productos al carrito
- Puedes asignar precios y stock diferentes para cada variante
- Las variables inactivas no estarán disponibles para asignar a productos nuevos
- Puedes tener múltiples variables en un mismo producto (ej: Talla + Color)
