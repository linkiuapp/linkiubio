# Inventario - Documentación para KiuBot Assistant

## Cómo gestionar el inventario

Para gestionar el stock de tus productos en Linkiu, sigue estos pasos:

1. En el menú lateral, ve a la sección "Tienda y productos"
2. Haz clic en "Inventario"
3. Verás una lista de todos tus productos con su información de stock:
   - Nombre del producto
   - SKU
   - Stock actual
   - Estado (Disponible, Stock bajo, Sin stock)
4. Usa los filtros en la parte superior para encontrar productos específicos:
   - Filtro por estado de stock (Todos, Disponible, Stock bajo, Sin stock)
   - Búsqueda por nombre o SKU
5. Para actualizar el stock de un producto:
   - Haz clic en el producto que quieres actualizar
   - Ingresa la nueva cantidad disponible
   - Haz clic en "Guardar"
6. El sistema te alertará automáticamente cuando el stock esté bajo

## Configuración de stock en productos

Al crear o editar un producto, puedes configurar:

1. Control de stock: Activa o desactiva el control de inventario para ese producto
2. Tipo de stock:
   - Ilimitado: El producto siempre está disponible
   - Limitado: Debes ingresar la cantidad disponible
   - Sin stock: El producto no está disponible
3. Umbral de stock bajo: Establece la cantidad mínima antes de que se marque como "stock bajo"
4. Para productos variables, puedes configurar el stock de cada variante individualmente

## Información adicional

- Los productos sin stock no se mostrarán como disponibles en tu tienda pública
- El sistema actualiza automáticamente el stock cuando se realiza una venta
- Puedes ver alertas de stock bajo en el dashboard
- Es importante mantener el inventario actualizado para evitar vender productos que no tienes
- Los productos con stock ilimitado siempre aparecerán como disponibles
